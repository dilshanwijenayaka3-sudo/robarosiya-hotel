ROBAROSIYA HOTEL WEBSITE - WHITE & GOLD THEME

FILES
- index.html
- style.css
- script.js

HOW TO RUN
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Double-click index.html, or use Live Server in VS Code.

IMPORTANT THINGS TO CHANGE
1. Hotel phone number and WhatsApp number:
   - Open script.js
   - Find: 94770000000
   - Replace with your real WhatsApp number using country code, no + sign or spaces.

2. Hotel contact details:
   - Open index.html
   - Replace:
     +94 XX XXX XXXX
     robarosiyahotel@example.com
     Add your hotel address here.

3. Room prices and room categories:
   - Search "From LKR --" inside index.html.
   - Replace with real prices.

4. Photos:
   This demo uses online sample photos.
   You can replace them with your own hotel photos later.

5. Google Map:
   Replace the map placeholder section with your Google Maps embed code.
